*2. Turning off Auto-annotation* - To turn off the auto-annotation feature
and require the annotator to use bitmask or polygon tools to draw the
vessel lumen manually, you can follow these steps:

*For bitmask annotations:*

   - Select the bitmask annotation type in the label editor.
   - Use the brush tool, which is selected by default when you choose a
   bitmask annotation.
   - Adjust the brush size using the slider in the bitmask popup.
   - Draw the vessel lumen manually using the brush.
   - When finished, click "Apply label" or press Enter.

*For polygon annotations:*

   - Select the polygon annotation type in the label editor.
   - Click on the editor canvas to start drawing your polygon.
   - Click to create each vertex of the polygon.
   - To complete the shape, either click on the first vertex or
   double-click to automatically close the polygon.

*To ensure manual annotation:*

   - Avoid using any auto-segmentation or tracking features.
   - Don't use the "Track object" option or the Shift + T shortcut for
   auto-segmentation tracking.
   - Instruct annotators to draw the vessel lumen manually using either the
   bitmask brush tool or the polygon tool.

*3. Adding additional annotators to a study:*

   1. Open the project you want to add annotators to.
   2. Click on the Annotate component in your workflow.
   3. Choose the "Selective" tab.
   4. Type the email address of the user you want to add as an annotator.
   5. Select the user from the list that appears.
   6. Click "Add" to confirm the selection.
